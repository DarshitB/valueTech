# Background Images for Reports

## Required Files

### vkassociate_letter_head.png
- **Purpose**: Background image for CV reports
- **Dimensions**: Should be A4 size (612x1008 pixels or similar)
- **Format**: PNG with transparent background preferred
- **Usage**: Used as background for all generated CV reports

## Instructions

1. Place your `vkassociate_letter_head.png` file in this directory
2. The image will be used as the background for all generated CV reports
3. Make sure the image is properly sized for A4 format
4. The system will automatically use this image when generating reports
